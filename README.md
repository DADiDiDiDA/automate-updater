# 自动化更新器

一个带玻璃质感的 Windows 桌面程序，用来批量检测并更新本机那些「从 GitHub 下载的绿色版程序」。
支持 git 克隆仓库与 Release 压缩包两类，自动处理代理/镜像，覆盖前自动备份，可以常驻托盘定时检查。

## 双击即用

- 程序本体：`D:\玩机工具\更新\AutomateUpdater.exe`（单文件，首次启动约 2–4 秒）
- 配置/记录：同目录 `config.json`、`records.json`（便携，随文件夹搬走）
- 源码目录：`D:\玩机工具\更新\AutomateUpdater\`

打开后会自动检查一次更新，列出有新版本的程序、版本变化和更新日志。重复双击不会再开第二个窗口，而是把已有窗口叫到前面。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 多检查文件夹 | 可添加任意多个根目录，每个根目录可单独排除内部子文件夹（如 `My-maawork`、`Cache`） |
| 两类来源 | `GIT`（git 克隆仓库，按提交数比较并 fast-forward）与 `Release`（GitHub 发布压缩包） |
| 来源筛选 | 按「全部 / 有更新 / Git / Release / 失败」筛选，支持搜索 |
| 两级排序 | 基础排序（名称 A→Z / Z→A、体积大→小 / 小→大、最近发布 / 最早发布）+ 特殊规则（有更新最先 / 不额外排序 / Git 优先 / Release 优先） |
| 版本变化 | 直接显示 `旧版本 → 新版本`；git 仓库显示提交短哈希 |
| 手动标记版本 | 程序目录里读不到版本号时，右键「手动标记本地版本」填一个版本，就能正常比对并参与批量更新 |
| 更新日志 | 展开每一行的「日志」：Release 显示 GitHub 发布说明，git 显示将要拉取的提交记录 |
| 两种安装方式 | `只保留指定文件夹`（删掉旧的无关文件再解压新版）/ `直接覆盖`（全部旧文件保留，只替换同名内容），设置里随时切换 |
| 按程序定制保留 | 右键「更新时保留的文件夹…」可为单个程序勾选要保留的子文件夹，覆盖全局设置 |
| 自动备份 | 覆盖前把整个程序目录备份到 `<根目录>\Cache\_backup`，可回滚 |
| 右键菜单 | 立即更新、绑定仓库、打开 GitHub 仓库、手动标记本地版本、更新时保留的文件夹、打开文件夹、复制路径、排除此文件夹 |
| 更新超时 | 单个程序下载 + 解压总时长超过设定值（默认 10 分钟）自动中止 |
| 静默执行 | 检查与更新时调用的 git / tar 等命令都不弹控制台窗口 |
| 单实例 | 只允许一个进程；再次启动会唤起已有窗口 |
| 网络自适应 | 代理可选自动探测 / 手动指定 / 不使用；再走直连与 10 个 GitHub 镜像并发测速，每天自动重测一次 |
| 后台常驻 | 关闭窗口最小化到托盘；托盘悬停显示程序名、上次检查时间、新版本数量 |
| 开机自启 | 写当前用户启动项，开机后在后台静默运行，不弹主界面 |
| 定时检查 | 15 分钟 ~ 24 小时任选，发现更新可按策略处理 |
| 更新策略 | 只通知 / 静默更新后提示 / 完全静默更新 |
| 通知方式 | 系统通知、钉钉机器人、弹出主界面（可多选，钉钉配置在同一个可展开项里） |
| 三套皮肤 | 亚克力（玻璃模糊）/ 莫奈（Material You）/ Miuix（澎湃 OS 风格） |
| 明暗模式 | 跟随系统 / 浅色 / 深色，可一键切换 |
| 毛玻璃开关 | 设置里可关闭；关闭后为不透明纯色，低配机器更流畅 |

## 设置说明

设置页分「一般设置 / 关于」两页，所有选项都是「图标 + 标题 + 说明 + 右侧控件」的行式布局。

**用户界面**：皮肤、明暗模式、毛玻璃开关。

**后台与自动更新**
- 关闭窗口时最小化到托盘：托盘右键「退出」才真正结束程序。
- 开机自动启动：写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`（值名 `AutomateUpdater`），
  命令行带 `--tray`，开机后只驻留托盘。移动文件夹后重新打开一次该开关即可刷新路径。
- 定时检查更新 + 间隔：程序在后台按间隔自动扫描。
- 发现新版本时：
  - `只通知，不自动更新`（默认）—— 只发通知，等你操作；
  - `静默更新，完成后提示` —— 后台直接更新，结束后发通知；
  - `完全静默更新` —— 后台更新且不打扰。
- 通知方式（可展开的一项）：系统通知 / 钉钉机器人 / 弹出主界面可多选；
  勾选钉钉后，同一张卡片里展开 Webhook 端点、加签密钥和「发送测试」。

**更新策略**
- `安装方式`：
  - `只保留指定文件夹`（默认）—— 删除名单外的旧文件，再解压新版，目录最干净；
  - `直接覆盖` —— 不删除任何已有文件，只用新版里的同名内容替换，适合压缩包里带一堆可选资源的情况。
- `默认保留的文件夹`：`User / config / data / saves / logs / profiles / 3rdparty` 一键开关（默认全开），
  下方输入框可补充自定义名字（逗号分隔）。仅在「只保留指定文件夹」模式下生效。
- 单个程序要单独定制时：列表行右键 →「更新时保留的文件夹…」，
  勾选该目录里的子文件夹（也可补充名单外的名字），还能一键「跟随全局」。
- `单个程序更新超时`：默认 10 分钟。
- `覆盖前自动备份` + 保留份数：备份目录 `<根目录>\Cache\_backup\<程序名>_<时间>`。

**检查文件夹**：添加根目录后，可点「排除…」逐行填写要跳过的子文件夹；列表行右键也能直接排除某个程序文件夹。

**网络**
- `本地代理`：`自动探测`（默认，扫描常见代理端口）/ `手动指定`（下方填写代理地址）/ `不使用代理`。
  手动地址支持 `http://` 与 `socks5://`，形如 `http://127.0.0.1:7890`；改完立即生效，不用重启。
- `GitHub 镜像加速`：内置 10 个公共镜像，默认开启。
- `每天自动测速一次`：可关；右侧「立即测速」手动并发测速全部镜像。

## 托盘

- 悬停提示：`自动化更新器 / 上次检查：x 分钟前（22:14）/ N 个程序有新版本`，
  有新版本时图标右上角带红色数字角标。
- 右键菜单：打开主界面、打开设置、立即检查更新、静默更新（N）、停止当前任务、开机自动启动、退出。

## 更新是怎么做的

1. 检查：git 仓库 `fetch` 后比较落后提交数；Release 程序调用 GitHub API 取最新 tag 与压缩包。
2. 更新 Release：下载 → 解压 → 用「锚点文件」剥掉压缩包里多余的多层目录 → 备份 →
   按安装方式处理（清除名单外旧文件 / 直接覆盖）→ 写入新版。
3. 更新 git：`fetch` + `merge --ff-only`；工作区有未提交改动时不会动它，只在列表里标记「跳过」。

> 「锚点文件」指 `interface.json`、`MAA.exe`、`BetterGI.exe` 这类能标识程序根目录的文件，
> 所以压缩包是单层还是 `包名/包名/文件` 两层都能正确定位。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+1 / 2 / 3` | 首页 / 程序 / 设置 |
| `F5` | 重新检查 |
| 右键列表行 | 更新 / 绑定仓库 / 打开 GitHub 仓库 / 手动标记版本 / 保留文件夹 / 排除文件夹 |

双击列表某一行 = 打开该程序所在文件夹。
未识别到 GitHub 仓库的程序（如 `BBchannel`）会显示「未绑定」，点「绑定仓库」填入 `owner/repo` 即可启用。

## 配置文件（便携）

配置与 exe 同目录：`config.json`（目录不可写时退回 `%APPDATA%\AutomateUpdater`），
`records.json` 记录上次检查时间与程序版本，崩溃日志写到同目录 `crash.log`。
整个文件夹可以随意复制或移动到别的路径，配置跟着走。

## 从源码运行 / 重新打包

```powershell
cd D:\玩机工具\更新\AutomateUpdater
python app.py                 # 直接运行
python app.py --tray          # 后台静默启动（开机自启用这个）
python -m PyInstaller --noconfirm --clean --onefile --windowed `
  --name "AutomateUpdater" --icon "D:\玩机工具\更新\AutomateUpdater\assets\icon.ico" `
  --add-data "D:\玩机工具\更新\AutomateUpdater\assets;assets" `
  --distpath "D:\玩机工具\更新" app.py
```

依赖：`PySide6`、`pillow`（打包用 `pyinstaller`，可选 `py7zr`）。

## 已知限制

- `.7z` 包需要 `py7zr` 或本机安装 7-Zip；都没有时该程序会提示「解压失败」。
- 未绑定的程序（没有 GitHub 仓库）不会被更新，只做提示。
- 程序正在运行时该程序会被跳过，避免文件占用。
- 系统通知依赖 Windows 通知中心；关闭「专注助手 / 勿扰」才能看到。
- 体积排序统计的是本地目录大小（跳过 `.git`），首次扫描会略微增加耗时。
